خلاصه

توسعه‌دهنده‌ی فرانت‌اند با بیش از سه سال سابقه‌ی حرفه‌ای در React و TypeScript، که دو سال آن روی یک ERP سازمانی با حدود ۸۰ صفحه گذشته است. برای اپلیکیشن‌های تجاری پرداده معماری قابل‌استفاده‌ی مجدد می‌سازم: ترکیب تایپ‌شده‌ی صفحه‌ها، جدول و فرم مشترک، و workflowهای مبتنی بر route. بک‌اند ASP.NET Core و SQL Server را هم توسعه می‌دهم و با Docker مستقر می‌کنم.

مهارت‌ها

فرانت‌اند: React, TypeScript, JavaScript, Next.js, TanStack Query, TanStack Router, React Router, Zustand, React Hook Form, Zod, Tailwind CSS, Vite

مهندسی UI: جدول و فرم‌های پرداده، معماری کامپوننت، رابط راست‌چین فارسی، طراحی واکنش‌گرا

بک‌اند (مکمل): .NET Core, EF Core, Node.js, Express, SQL Server, PostgreSQL, REST APIs

ابزارها: Git, Docker, Nginx, CDN, Azure, Stimulsoft Reports

توسعه با کمک AI: Claude Code, Codex, custom agent skills, MCP
