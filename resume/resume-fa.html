خلاصه

توسعه‌دهنده‌ی فرانت‌اند با بیش از سه سال سابقه‌ی حرفه‌ای در React و TypeScript، شامل دو سال توسعه‌ی سیستم ERP یکپارچه با حدود ۸۰ صفحه. تمرکز اصلی بر طراحی معماری‌های قابل‌استفاده‌ی مجدد برای سامانه‌های سازمانی پرداده، از جمله سیستم ساخت صفحه مبتنی بر factory، جداول و فرم‌های مشترک و گردش کار درخواست‌ها. دارای تجربه در توسعه‌ی بک‌اند با ASP.NET Core و SQL Server، استقرار با Docker و به‌کارگیری ابزارهای هوش مصنوعی در فرایند توسعه.

مهارت‌ها

فرانت‌اند: React, TypeScript, JavaScript, Next.js, TanStack Query, TanStack Router, React Router, Zustand, React Hook Form, Zod, Tailwind CSS, Vite

مهندسی UI: جدول و فرم‌های پرداده، معماری کامپوننت، رابط راست‌چین فارسی، طراحی واکنش‌گرا

بک‌اند (مکمل): .NET Core, EF Core, Node.js, Express, SQL Server, PostgreSQL, REST APIs

ابزارها: Git, Docker, Nginx, CDN, Azure, Stimulsoft Reports

توسعه با کمک AI: Claude Code, Codex, custom agent skills, MCP
